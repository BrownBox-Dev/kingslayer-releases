# KingSlayer — downloads

Baixe o instalador na última [release](https://github.com/BrownBox-Dev/kingslayer-releases/releases/latest) (`KingSlayer-Setup-x.y.z.exe`).

Depois de instalado, o jogo verifica sozinho se há uma versão nova (ao abrir e a cada meia hora) e pergunta se você quer atualizar. Seu progresso e suas configurações são mantidos.
